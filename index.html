Markdown Task Importer

Create tasks and subtasks from an indented Markdown outline. Add Markdown notes and grouped checklists to each task before importing.

Preview

A [Project name] line switches to an existing project.
Ctrl/Cmd-click to select several tags.
Use - Task for tasks and indented - Subtask for subtasks. Indented - [ ] and - [x] lines become checklist items. A standalone **Category** line labels the following checklist group. Other indented lines become Markdown notes for the current task. Only one subtask level is supported.
