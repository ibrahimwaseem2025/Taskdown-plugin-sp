Bulk Add Tasks

Paste one task per line. Optional [Project name] headings switch project, indentation creates subtasks, existing #tags can be parsed from task titles, and ((notes)) are added to the created task.

Preview

Used until a [Project name] heading changes it.
Ctrl/Cmd-click to select several tags.
Indentation is relative. Only two levels are supported: tasks and their subtasks. A subtask cannot have its own subtasks. Project headings are matched case-insensitively against existing projects.
